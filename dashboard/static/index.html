Facturas Dudosas (Resolución de Fechas)

Detectadas con día y mes ≤ 12 sin regla previa. Selecciona la opción correcta o descártala si no es válida.

¿Cómo funcionan las opciones A y B? Las fechas de Opción A y B se calculan dinámicamente a partir de los números que el modelo extrae de cada documento específico (por ejemplo, si una factura tiene 04/11, verás 4 de Noviembre frente a 11 de Abril). Al confirmar, el sistema memoriza el formato de ese proveedor para no volvértelo a preguntar.
